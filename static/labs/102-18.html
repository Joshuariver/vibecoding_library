18. ICL · RAG · CPT 방식 구분

새로운 지식을 AI에게 알려 주는 세 가지 방법을 입력 자료와 모델 가중치 변화 여부로 구분해 봅니다.

ICLRAGCPT
방식하는 일모델 가중치바로 쓸 수 있나
ICL (문맥 내 학습)예시나 자료를 질문과 함께 입력에 넣는다변하지 않음바로 가능
RAG (검색 증강 생성)저장된 문서에서 관련 내용을 찾아 입력에 넣는다변하지 않음검색 환경을 갖추면 가능
CPT (지속 사전 학습)대규모 자료로 모델을 추가 학습한다변함별도 학습 후 적용

① 시나리오 분류

② RAG 검색 시뮬레이션 시뮬레이션

고정된 예시 자료 4건과 단순 키워드 일치로 흉내 냅니다. 실제 검색 DB에 연결하거나 모델을 학습하지 않습니다.

제품 매뉴얼 30페이지 같은 예시는 모델의 입력 한도와 문서 품질에 따라 달라집니다. 이 화면의 점수는 학습용 피드백이며 공식 평가가 아닙니다.
