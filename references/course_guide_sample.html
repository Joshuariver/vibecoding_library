🛠️ 실습 사전 준비: 4단계 환경 구축 가이드
STEP 1

Visual Studio Code (VS Code) 설치

소요 시간: 약 5~10분

Visual Studio Code는 AI(Antigravity CLI)가 만들어 주는 코드와 파일을 눈으로 직접 확인하고 편집하는 작업 화면(에디터)입니다.

💡
회사 PC 권장 설치 방식: User Setup
관리자(Admin) 권한이 없어도 %LOCALAPPDATA% 경로에 안전하게 설치되며 자동 업데이트를 지원합니다.

1. 공식 다운로드 및 설치

공식 사이트에서 다운로드 후 실행합니다: VS Code User Setup 다운로드 (Windows)

⚠️
설치 마법사 실행 시 필수 체크 항목!
[추가 작업 선택] 화면에서 "PATH에 추가 (다시 시작한 후 사용 가능)" 옵션을 반드시 체크해야 터미널에서 code . 명령어를 바로 사용할 수 있습니다.

2. 한국어 팩 및 필수 확장(Extension) 원클릭 설치

새로 연 PowerShell 터미널에 아래 명령어를 복사하여 붙여넣으면 한글 언어팩과 AI 실습에 필요한 핵심 확장이 일괄 설치됩니다.

PowerShell (필수 확장 일괄 설치) 
code --install-extension MS-CJKLM.vscode-language-pack-ko
code --install-extension yzhang.markdown-all-in-one
code --install-extension ms-vscode.live-server
code --install-extension bierner.markdown-mermaid
code --install-extension yzane.markdown-pdf
code --install-extension tomoki1207.pdf
VS Code 준비 완료 체크리스트 진행 상황이 브라우저에 자동 저장됩니다
STEP 2

Antigravity CLI (agy) 설치

소요 시간: 약 10~15분

Antigravity CLI는 터미널에서 AI 에이전트와 자연어로 대화하며 프로그램 코드를 생성하고 자율 디버깅을 수행하는 본 교육의 핵심 도구입니다.

1. 운영체제별 원클릭 설치 명령어

PowerShell(Windows) 또는 터미널(macOS) 창에 아래 명령어를 복사 후 Enter를 누르세요.

Windows (PowerShell) 
irm https://antigravity.google/cli/install.ps1 | iex
macOS / Linux 
curl -fsSL https://antigravity.google/cli/install.sh | bash

2. 설치 확인 및 최초 Google 로그인

열려 있는 터미널을 완전히 닫고 새 터미널을 연 후 실행합니다.

터미널 (실행 및 로그인) 
agy --version
agy
🎉
agy를 입력하면 웹 브라우저가 자동으로 열립니다. Google 계정으로 로그인하고 [허용/Allow]을 누르면 즉시 연동 완료됩니다!
Antigravity CLI 준비 완료 체크리스트
STEP 3

Python (파이썬) 설치

소요 시간: 약 10~15분

Python은 수강생이 문법을 외우기 위한 것이 아니라, AI가 만들어 준 데이터 분석 및 엑셀 자동화 코드를 내 컴퓨터에서 작동시키는 '실행 엔진' 역할을 합니다.

1. 공식 인스톨러 다운로드

공식 웹사이트 접속: Python 공식 다운로드 (Python 3.11 또는 3.12 권장)

⚠️
[가장 중요] 첫 설치 화면 맨 아래 체크박스 필수 확인!
인스톨러 첫 화면 하단의 [ Add python.exe to PATH ] 체크박스에 반드시 체크 후 [Install Now]를 클릭해야 합니다. 체크하지 않으면 터미널에서 명령어가 인식되지 않습니다.

2. 정상 설치 1초 테스트 & pip 최신화

새 터미널을 열고 아래 명령어를 순서대로 실행하여 파이썬 런타임과 패키지 관리자가 정상 동작하는지 검증합니다.

터미널 (버전 확인 & 1초 테스트) 
python --version
python -c "print('Hello, Vibe Coding!')"
python -m pip install --upgrade pip

💡 자주 겪는 문제 해결

Q. 'python'을 입력했는데 마이크로소프트 스토어가 열립니다.
Windows 작업표시줄 검색창에 "앱 실행 별칭"을 검색하여 실행한 뒤, python.exe 및 python3.exe 항목의 스위치를 [끔(Off)]으로 변경하고 터미널을 재시작하세요.
Q. 'python은(는) 내부 또는 외부 명령... 이 아닙니다' 에러가 납니다.
설치 시 Add python.exe to PATH를 체크하지 않았을 때 발생합니다. 다운로드한 설치 파일을 다시 실행하여 [Modify]를 누르고 환경 변수 추가를 체크 후 다시 설치하세요.
Python 준비 완료 체크리스트
STEP 4

Git (깃) 설치

📌 개발조직 / 엔지니어 대상 (영업직군은 선택)

Git은 로컬 PC에서 AI와 함께 작성한 프로그램 코드와 설정을 사내 DEJ Workspace(서버)로 안전하게 올려서 배포(Publish)하기 위한 '필수 전송 도구'입니다. (비SW 개발직군 / HW·기구·품질·생산기술 엔지니어 및 DEJ 배포 예정자 필수)

1. 다운로드 및 설치 핵심 3대 옵션

공식 다운로드 페이지: Git for Windows 64-bit 다운로드

💡
설치 마법사 시 [Next] 누르며 주의할 3가지 화면:
1. 기본 편집기(Editor): "Use Visual Studio Code as Git's default editor" 선택
2. PATH 환경변수: "Git from the command line and also from 3rd-party software" 선택
3. 줄바꿈(Line ending): "Checkout Windows-style, commit Unix-style line endings" 선택

2. 설치 확인 및 최초 1회 사용자 정보 등록

새 터미널을 열고 본인의 이름과 회사 이메일을 등록합니다. (사내 DEJ 서버 배포 시 필수)

PowerShell (사용자 등록 & 한글 깨짐 방지) 
git --version
git config --global user.name "홍길동"
git config --global user.email "gildong.hong@company.com"
git config --global core.quotepath false
⚠️
사내 보안망 SSL 인증서 에러 발생 시 임시 해결법:
회사 네트워크(프록시)에서 SSL certificate problem이 발생할 경우 터미널에 git config --global http.sslVerify false를 입력하여 우회할 수 있습니다.
