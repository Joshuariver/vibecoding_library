바이브코딩 라이브러리 – 사용 안내
================================

1. 시작하기
   - 이 폴더의 index.html 을 더블클릭하면 브라우저(Chrome 또는 Edge 권장)에서 열립니다.
   - 인터넷 연결, 설치, 서버가 필요 없습니다.
   - 압축 파일(zip)로 받았다면 반드시 "압축을 푼 뒤" 열어 주세요. (압축 안에서 바로 열면 일부 기능이 동작하지 않습니다.)

2. 학습 순서
   - 101 입문 → 102 중급 → 103 고급(해외영업 / R&D 중 선택)
   - 103 은 102 의 "졸업 체크리스트"를 모두 완료하면 열립니다.
   - 각 레벨은 가이드(읽기) · 체험관(직접 해보기) · 퀴즈·체크로 구성됩니다.

3. 이럴 땐 이렇게
   - 용어가 헷갈리면: 왼쪽 메뉴 "용어 사전" 또는 Ctrl+K 로 검색
   - 바로 쓸 프롬프트가 필요하면: "프롬프트" 메뉴에서 복사 / [대괄호] 빈칸 채우기
   - 내 진도 확인: "내 학습"

4. 진도 저장
   - 진도·퀴즈 점수·즐겨찾기는 이 PC의 이 브라우저에 저장됩니다.
   - 다른 PC나 다른 브라우저에서는 처음부터 시작되며, 저장된 기록을 지우면(브라우저 사용 기록 삭제 등) 사라집니다.
   - "내 학습" 화면에서 학습 기록을 파일로 내보낼 수 있습니다.

5. 화면이 이상할 때
   - 오래된 브라우저에서는 일부 화면이 다르게 보일 수 있습니다. 최신 Chrome 또는 Edge 를 사용해 주세요.
   - 폴더 안의 파일(data, labs, css, js 폴더)을 일부만 옮기면 동작하지 않습니다. 폴더 전체를 함께 옮겨 주세요.
