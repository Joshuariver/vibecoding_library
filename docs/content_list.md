### 3. 퀴즈/체크

**실천 체크리스트** — 실천 체크리스트 (7개)

1. 작게 시작하세요. 한 번에 완성품을 요구하지 말고 MVP → 기능 추가 순으로 갑니다.
2. 한 번에 하나만 요청하세요. 여러 수정을 섞으면 어디서 문제가 생겼는지 알 수 없습니다.
3. 직접 실행해서 확인하세요. AI가 "완료"라고 해도 반드시 눈으로 확인합니다.
4. 에러는 통째로 복사해서 붙여넣으세요. 요약하지 말고 원문 그대로가 가장 정확합니다.
5. 자주 저장(커밋)하세요. 잘 되는 시점마다 저장해 두면 언제든 되돌릴 수 있습니다.
6. 모르면 물어보세요. "이게 무슨 뜻이야?", "왜 이렇게 했어?"는 최고의 학습 방법입니다.
7. 비밀 정보는 절대 넣지 마세요. 비밀번호, API 키, 고객 개인정보, 사내 기밀은 프롬프트나 코드에 넣지 않습니다.

### 3. 퀴즈/체크

**실천 체크리스트** — 졸업 체크리스트 (10개)

1. 문제 정의서(입력·출력·단위·정확도·규격)를 작성할 수 있다
2. 장비 데이터 파서와 품질 점검을 만들고 검증한다
3. 원본 데이터 불변 원칙과 폴더 구조를 지킨다
4. 단위를 명시하고 단위 오류를 자동으로 잡도록 구성한다
5. 정답 기반 테스트와 독립 교차 검증을 수행한다
6. 통계 가정·적용 범위·한계를 문서화한다
7. 재현성(버전 고정, 시드, 입력 해시)을 확보한다
8. AI 결과를 비판적으로 검토시키고 전문가 리뷰를 요청할 수 있다
9. 기밀·IP·안전·규제 이슈를 구분하고 관련 부서와 협의한다
10. 반복 분석을 Skill/설정 파일로 만들어 팀과 공유한다
