## 마크다운: AI 친화적인 Format

### 1. 작성 프롬프트 문(예시)
```
제공된 글을 Markdown 형식으로 변환해 주세요.
제목, 부제목, 목록, 인용문, 코드 블록 등 Markdown 문법을 적절히 활용해 가독성을 높여 주세요.
원문의 의미나 구조를 유지하면서 문단을 명확히 구분해 주세요.
불필요한 공백이나 중복 표현은 정리해 주세요.
최종 결과는 문서 보관용으로 깔끔하고 일관된 형식을 갖추도록 해 주세요.
```
### 2. 마크다운의 장점
-  Markdown은 “사람이 읽기 쉬운 구조”와 “기계가 이해하기 쉬운 규칙성”을 동시에 제공하기 때문에, AI 학습 데이터로 매우 효율적입니다.
#### 1) 구조적 정보 제공
- Markdown은 제목(##), 목록(-), 코드 블록( ```), 인용문(>) 등으로 문서의 논리적 구조를 명확히 구분합니다.  이런 구조는 AI가 문서의 계층 관계나 문단의 역할을 쉽게 파악하도록 도와줍니다.

#### 2) 의미 단위 구분이 용이
    - 일반 텍스트는 문단 경계나 강조 부분을 구분하기 어렵지만, Markdown은 강조(**bold**), 링크, 표 등을 통해 의미 단위를 명확히 표현합니다.  이는 AI가 문맥을 분석할 때 중요도나 관계성을 더 정확히 학습하게 합니다.

#### 3) 일관된 형식으로 대량 학습 가능
    - Markdown은 단순하고 규칙적인 문법을 가지므로, 다양한 문서에서도 일관된 패턴을 유지할 수 있습니다.  이런 일관성은 AI가 형식적 패턴과 의미적 패턴을 동시에 학습하는 데 유리합니다.

#### 4) 노이즈(불필요한 정보) 감소
    - HTML이나 PDF와 달리, Markdown은 표현을 위한 불필요한 태그나 스타일 정보가 적습니다.  따라서 AI는 콘텐츠 자체에 집중할 수 있습니다.

#### 5) 배포의 용이성
    - VS Code 를 사용해서 손쉽게 배포하기 좋은 PDF 나 html 파일로 전환하기 용이합니다.


## 메타 프롬프팅: 
### 1. 개념
- AI에게 직접 답변만 작성하게 하는 대신, "더 좋은 프롬프트, 템플릿, 규칙, 혹은 사고 구조를 설계하도록 지시하는 프롬프트 엔지니어링 방법론"입니다. 
- 즉, '질문에 대한 답'을 구하는 것이 아니라 'AI가 질문을 어떻게 해석하고 최상의 답변을 만들어낼지'에 대한 규칙(프롬프트)을 AI 스스로 설계하게 만드는 방식입니다
### 2. 용도 및 기대효과
- 반복적인 보고서 작성, 주간 회의록, 코드 리뷰, 마케팅 카피 등 출력 형식과 퀄리티가 일정해야 하는 업무
- 사용자가 초보자라서 AI에게 올바른 맥락과 지시사항을 어떻게 전달해야 할지 모를 때
- 프롬프트를 매번 새로 궁리할 필요 없이 재사용 가능한 템플릿 확보
- AI의 환각(Hallucinaton)을 줄이고 논리적 추론 및 일관성 강화
- 프롬프트 제작 시간을 단축하고 업무 효율 극대화


## 문맥 내 학습(In-Context Learning)

### 1. 개념
- 데이터로 제공된 새로운 정보나 예시를 바탕으로 주어진 과제를 수행하는 능력 또는 방식

### 2. AI의 학습 방식의 종류
#### 1) In-Context Learning (ICL: 문맥 내 학습)
- LLM에 처음보는 30페이지 짜리 제품 매뉴얼을 제공하고, 이에 따라 해당 제품의 사용법에 대한 답변을 생성하게 함. 새로운 도메인 지식을 실행시점에 컨텍스트로 주입. 즉시 활용이 가능하며 모델 가중치 변경은 없음.

#### 2) Retrieval-Augmented Generation (RAG:검색 증강 생성)
- LLM에 법률, 의료, 제품 개발 전체 공정 등의 전문 지식DB를 연결하고, 질문에 관련된 자료를 검색해 답변하게 하는 방식. 외부 전문지식 DB에서 관련정보를 검색해 답변에 반영. 즉시 활용이 가능하며 모델 가중치 변경은 없음.

#### 3) Continued Pretraining (CPT:지속 사전 학습)
- 특정 분야의 대규모 데이터를 추가 학습시켜 해당 도메인의 언어와 지식에 대한 모델 내부 표현을 개선하는 방법. 모델 자체에 대규모 데이터를 학습시켜 LLM을 전문화. 별도 학습이 필요하여 즉시 활용은 불가능하며, 적용 이후에 모델 가중치 변경이 있음.
