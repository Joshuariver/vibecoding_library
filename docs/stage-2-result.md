# 2단계 결과 — app4 사본 생성과 과정 데이터

완료일: 2026-10-30  
단계 범위: 계획서의 2단계. 이후 도구 데이터·상태·화면 구현은 아직 진행하지 않음.

## 수행한 작업

- app1의 앱 파일 74개를 app4로 복사했다. 기존 app4/docs의 1단계 문서 3개는 유지했다.
- 복사 전 대상 파일 충돌과 원본 기준선부터 확인했다. 가상환경·캐시·Git 메타데이터는 복사 대상에서 제외했다.
- `static/data/courses.js`를 신규 작성했다. 기존 `window.VCL`을 유지하고 `VCL.courses`에 데이터만 추가한다.
- 두 과정의 제목·부서·소개·러닝넷 검색명·목표·회차·시간표·준비사항·문의처·원본 위치·검토일을 구조화했다.
- 문의 담당 2명은 공통 contacts에 두고 각 과정에서 ID로 참조한다. 현재 담당 여부 확인 필요 문구를 함께 둔다.
- 회차는 과정 본문과 별도 sessions 배열에 두었다. 2026-10-19/26은 past, 신청은 closed, 확인되지 않은 신청 URL은 null로 명시했다.
- 원본의 등록 후 설문 안내는 보존하되 지난 회차 안내라는 문맥을 추가했다.
- 고급 관련 트랙은 103s/103d ID만 참조한다. 기존 잠금 계산을 중복 정의하지 않았다.

경고는 0단계와 같은 Starlette TestClient의 httpx 사용 중단 예정 안내다. 이번 단계에서 의존성을 변경하지 않았다. 데이터 검증 첫 실행에서는 PowerShell→Node 파이프에서 검증 코드의 한국어 상수가 손상되었다. 검증 코드의 상수를 Unicode escape로 전달해 다시 실행했고 통과했다. 과정 파일의 한국어 내용은 원본 비교에서 정상 확인했다.

## 현재 상태와 다음 단계

화면·메뉴·라우터·검색은 복사된 원본 상태다. courses.js의 index.html 로드 및 교육 화면 연결은 6단계에서 수행한다. 이번에는 데이터 자산 제공과 원본 대조를 확인했으며 새 교육 화면의 브라우저 검증을 완료했다고 주장하지 않는다.

다음 3단계는 `static/data/setup.js`에 도구 5개, 체크 16개, 원본 체크 매핑, 필수 조건·준비율 계산을 추가하는 작업이다. 사용자 “다음” 전까지 멈춘다.
