## 구현한 흐름

- **홈 화면 (`#/`)**:
  - 기존 히어로 영역 바로 아래에 '교육 안내'와 '시작 준비'로 구성된 `home-start` 카드를 배치했습니다.
  - 시작 준비 카드는 사용자의 직군/도구 선택 상태에 따라 '준비 시작하기' 또는 '준비 완료율'과 함께 '준비 이어하기'로 안내합니다.
- **사이드바 메뉴**:
  - 홈 아래에 `시작하기` 그룹을 두고 `교육 안내`(`#/courses`)와 `시작 준비`(`#/setup`) 링크를 배치했습니다.
- **내 학습 (`#/me`)**:
  - 기존 레벨별 진도 테이블 아래에 '시작 준비 현황' 카드(`.me-setup`)를 배치했습니다.
  - 준비 완료율과 함께 도구별 필수/선택 구분 및 완료 상태(완료 수 / 전체 체크 수)를 표시합니다.
  - 준비율은 기존 학습 진도 및 103 해금 조건과 독립적으로 유지됩니다.
- **통합 검색 (Ctrl+K)**:
  - 교육 안내(`course`)와 시작 준비(`setup`) 유형이 검색 결과에 표시됩니다.
  - Codex 세부 기능(인증, 명령, 권한, 자동화, 업데이트, 문제 해결 등) 검색 시 해당 도구와 하위 절로 직접 이동합니다.
  - 직군이 아직 선택되지 않은 경우 직군 선택 안내 경로(`#/setup/choose/...`)를 통해 이동 후 목적 도구로 안내합니다.
  - 기존 103 잠금 단계 내용 숨김 필터와 기존 용어/프롬프트 검색 기능은 변함없이 정상 동작합니다.
