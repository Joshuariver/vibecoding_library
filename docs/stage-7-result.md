## 구현 내용

- 상단에서 직군, AI 도구 0~2개, 배포 예정 여부를 선택한다. 비SW개발은 배포 여부와 무관하게 Git 필수이며 일반 영업은 배포 예정일 때 Git을 필수로 포함한다.
- 선택한 도구만 필수 준비율에 반영한다. AI 미선택 상태는 진행률 막대 대신 선택 안내를 제공한다.
- 선택 후 “시작 준비 완료율 70% / 완료 7 / 필수 10” 형태로 비율과 개수를 표시하고 학습 진도와의 차이를 설명한다.
- VS Code → Antigravity → Codex → Python → Git 순서로 독립 도구 카드를 제공한다. 각 카드에 필수·선택·선택 안 함과 자체 완료 개수를 표시한다.
- 선택하지 않은 AI 도구도 펼쳐 읽거나 체크할 수 있지만 필수 준비율에는 합산하지 않는다. 직군·배포 여부·도구 선택을 바꿔도 체크는 유지한다.
- 도구마다 이유, 설치 방식 선택, 공식 링크·명령 복사, 확인·로그인·도움말, 완료 체크, 출처·검토일을 표시한다.
- 설치 방식은 한 번에 하나만 표시한다. Codex의 npm 방식에서만 Node.js/npm 준비 안내가 나타난다. 설치 방식 선택은 현재 페이지 세션에서 유지하며 이번 단계에서는 새 저장 필드로 추가하지 않았다.
- 상세 절은 접을 수 있고 버전 확인·인증·첫 실행 등 핵심 절을 먼저 펼친다. 나머지 사용법을 모두 읽는 것을 체크 완료 조건으로 삼지 않는다.
- 체크·AI·배포 변경 시 준비율·상태 배지·저장 안내만 갱신한다. 전체 화면을 다시 그리지 않아 해당 입력의 포커스와 펼친 설명이 유지된다.
- 저장 실패 시 현재 창의 변경을 유지하며 임시 상태 안내를 즉시 표시한다. 저장이 다시 가능해지면 현재 상태를 저장하고 안내를 제거한다.
- 준비 완료와 무관하게 101 학습 시작을 허용한다. 설치나 로그인을 앱에서 실행하지 않는다.

## 주소·복사

- `#/setup/sales`, `#/setup/dev`와 도구별 `#/setup/{직군}/{도구}` 지원.
- 하위 절은 `#/setup/dev/codex/auth`, `#/setup/dev/codex/usage`, `#/setup/dev/git/verify` 같은 형태로 해당 도구와 절을 펼쳐 이동한다. install/checks 절도 지원한다.
- 직군 탭은 현재 유효한 도구·절 경로를 이어간다. 잘못된 도구·절은 안내 문구와 기본 도구 목록 또는 해당 도구로 유도한다.
- 라우터의 기본 제목 포커스 처리 뒤에 실제 상세 제목을 포커스하고 스크롤한다. 고정 상단바에 가려지지 않도록 해당 대상의 scroll-margin도 적용한다.
- 복사는 기존 공통 copyText와 코드 블록 스타일을 사용한다. 기존 대체 복사의 execCommand가 false를 반환한 경우 성공으로 처리하던 부분을 최소 수정했다.
- 실패 시 직접 선택 가능한 코드와 실패 알림을 남긴다. 이번 검사에서 명령 문자열은 복사 동작만 모사했으며 설치·로그인 명령을 실행하지 않았다.

루트와 `/project/academy/test-user/proxy/8000/` 유지형 접두 경로를 각각 실제 브라우저에서 확인했다. 제거형 접두 경로는 기존 HTTP 검사에 포함된다. 실제 DEJ 게시 검증과 구분한다.

검증 환경은 Python 3.13.7·Node.js 24.18.0·기설치 Chrome/Playwright다. 기존 httpx 사용 중단 예정 경고는 유지되며 새 의존성 설치는 없었다. 테스트는 독립 브라우저 프로필과 모사 체크를 사용했다. 전체 키보드 흐름·복사 후 포커스·고급 실습 회귀는 최종 접근성·회귀 단계에서 추가 확인한다.
