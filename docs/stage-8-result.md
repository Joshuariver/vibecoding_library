## 구현한 흐름

- Codex 카드 상단에 설치와 버전 확인 → 로그인 → 첫 설명 요청의 바로가기를 제공한다. 관련 절을 펼치고 포커스를 옮긴다.
- 설치는 기존 네 방식 중 하나를 표시한다. npm에서만 Node.js/npm 준비를 안내하며 중복 설치를 요구하지 않는다.
- 로그인은 ChatGPT·기기 코드·API 키 중 선택한 안내만 표시한다. 기기 코드는 허용 조건과 beta 상태, API 키는 별도 과금·사전 환경 변수 준비 전제를 명시한다. [공식 인증 안내](https://learn.chatgpt.com/docs/auth).
- API 키 입력창·인증 파일 업로드·웹앱의 로그인 실행 기능은 없다. 코드 블록에는 환경 변수 이름만 있으며 실제 키를 읽거나 저장하지 않는다.
- 로그인 상태 확인은 각 방식에 포함하고 로그아웃은 별도로 접어 두어 시작 절차와 섞이지 않게 했다.
- 첫 실행은 프로젝트 폴더 열기 → Codex 입력창에 설명 요청 → 실제 파일과 답변 대조의 세 단계로 표현한다. macOS/Linux 명령은 별도로 펼쳐 읽는다.
- 일반 코드 블록에는 터미널·Codex 입력창·AGENTS.md 내용·config.toml 내용의 위치를 표시한다. 파일 내용 예시를 실행 명령으로 오해하지 않게 구분했다.
- 사용법은 터미널 명령 6개와 내부 슬래시 명령 6개를 구분하고 각각 하나씩 복사한다. 선택 가능한 모델명은 고정하지 않는다. [공식 슬래시 명령](https://learn.chatgpt.com/docs/cli/slash-commands).
- 권한 모드 예시와 자동화 작업 예시도 대안별 코드 블록으로 나눴다. 읽기 전용 예시와 수정 예시를 한 번에 실행하도록 복사하지 않는다.
- 설치 방식을 바꾸면 업데이트 절의 명령도 즉시 같은 방식으로 전환한다. 업데이트 후 버전 확인을 별도로 제공한다. [공식 설치·업데이트](https://learn.chatgpt.com/docs/codex/cli).
- 자동화는 일반 출력과 JSONL을 구분하고 기존 full-auto 미지원 안내를 유지한다. [공식 비대화형 안내](https://learn.chatgpt.com/docs/non-interactive-mode).
- 기본 명령·리뷰·권한·프로젝트 규칙·개인 설정·자동화·업데이트·문제 해결은 접어서 읽는다. 전체 상세 읽기를 준비 완료 조건으로 추가하지 않는다.

인증 방식·설치 방식 변경은 안내 표시만 바꾸며 설치·로그인·준비 체크를 자동 완료하지 않는다. 방식 선택은 현재 페이지 세션에서 유지하며 민감 정보를 저장하는 필드는 추가하지 않았다.

복사는 브라우저의 모사 Clipboard에 문자열을 전달하는 방식으로 확인했다. 실제 터미널 명령이나 환경 변수의 비밀 값을 실행·조회하지 않았다. 테스트 서버·브라우저는 종료했고 사용자 브라우저 프로필은 사용하지 않았다.
